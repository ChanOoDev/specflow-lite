# SpecFlow Lite — User Feedback Interviews

**Interviewer:** Chan Oo (@ChanOoDev)
**Date:** July 2026
**Product:** SpecFlow Lite — https://specflow-lite.vercel.app

---

## Interview 1: Solo Developer (Personal Use)

**Q: What problem does SpecFlow Lite solve for you?**
> Before SpecFlow, I scattered requirements across Google Docs, specs in Notion, and tasks in Jira. There was zero traceability — I couldn't tell which task tied to which requirement. SpecFlow puts everything in one place with full linkages.

**Q: What's the most valuable feature?**
> The specification pipeline. Being forced to write a spec before coding catches half the problems early. I used to jump straight into implementation and rewrite things 3 times. Now I write the spec once and implement once.

**Q: What's frustrating or missing?**
> No full-text search yet. When I have 50 requirements across 7 projects, I need to search across all of them. Also, no multi-user access — I can't share a project with a collaborator.

**Q: How does the AI-assisted workflow feel?**
> The agents are surprisingly consistent. The BA agent always asks the right clarification questions, and the reviewer catches things I'd miss. The graph-first hook is a game changer — it stops me from reading files I don't need to read.

**Q: Would you recommend this to other developers?**
> Yes, for anyone doing spec-driven development. The pipeline is the product — the UI is just the interface to enforce it.

## Interview 2: Non-Technical Project Manager

**Q: Can you describe what SpecFlow Lite does in your own words?**
> It's like a smart project notebook. You write what you want to build, it helps you think through the details, then breaks it into tasks. Everything is connected — you can see why each task exists.

**Q: Is the interface intuitive?**
> Mostly. The project → requirement → specification → task hierarchy makes sense. The dashboard gives a good overview. I'd love drag-and-drop for reordering tasks though.

**Q: What would make you use this daily?**
> Notifications when tasks are completed. Integration with Slack or email. And the ability to export specs to PDF for stakeholder reviews.
